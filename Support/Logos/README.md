# Service logos

These marks identify each service in the app's menu. They belong to their owners and are **not**
covered by this repository's MIT licence.

| File | Mark | Owner | Source |
| --- | --- | --- | --- |
| `claude-spark.svg` | Claude Spark | Anthropic | Anthropic's press kit, linked from [anthropic.com/news](https://www.anthropic.com/news) (`Claude Spark - Clay.svg`, unchanged) |
| `openai-blossom.svg` | Blossom | OpenAI | [openai.com/brand](https://openai.com/brand/) (`Blossom_Light.svg`; the mark's path, unchanged, framed on its own) |

The app draws each one in a single system colour, at the size of the text beside it, and only to
show which service a section belongs to. It's unofficial and not endorsed by either company.
